# Natural-Animal-Motion-with-HIL

The core investigation is whether Hybrid Imitation Learning (HIL) can produce natural looking and robust quadrupedal locomotion. The aim is to implement the results of the work of Jiashun Wang et al. in their paper titled "HIL: Hybrid Imitation Learning for Dynamic Athletic Control" but for simulated animal motion. I aim to take their work from simulation to reality in the eventual future. The motion is supposed to mimic that of a dog and will use motion capture data from the 3D Multi-modal Dog Dataset, 3DDogs (https://cvssp.org/data/3DDogs/). The dog model will be taken from the mujoco_menagerie github (https://github.com/google-deepmind/mujoco_menagerie). The model will be taken from the official code release of the paper (https://github.com/jiashunwang/Hybrid-Motion-Imitation).
